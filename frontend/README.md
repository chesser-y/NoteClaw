# NoteClaw Frontend

Vue 3 + Vite + TailwindCSS frontend for the NoteClaw knowledge workspace.

## Setup

```powershell
npm install
```

## Run

```powershell
npm run dev -- --host 127.0.0.1
```

Default local URL:

```text
http://127.0.0.1:5173/
```

## Build

```powershell
npm run build
```

## API Base

The frontend reads:

```text
VITE_API_BASE_URL
```

Default:

```text
http://127.0.0.1:8000/api
```
